# joutio-reusable-workflows

GitHub Actions réutilisables de l'organisation Joutio : workflows de CI et de release (services
Java, SDK, frontends), actions composites (setup Java/Maven et Node/npm, semantic-release,
build et push d'image, purge des paquets), Dockerfiles et configuration semantic-release partagée.

Documentation : [`docs/ops/ci.md`](../../docs/ops/ci.md) du workspace (usage, secrets, release,
rétention). Règles de modification : [`AGENTS.md`](AGENTS.md).
